I had an idea for a company that would create a line of products that would be so universal and useful that we would one day wonder how we lived without them. Near the end of that dream, there would be a digital currency to match a global world. That grows or shrinks on purpose, with use or lack of. When it reaches 0, we should have made it so that money has become irrelevant and unnecessary. Doesn't need to be the only currency, but there should be one multicentralized global currency. Needs to be backed at the start? Not if all? By what? Till then, what we have is the best we've come up with so far, or someone comes up with better!

Over a decade, hopefully less, taxes could be changed so instead of corporate taxes, there would only be dynamic marginal ownership share in companies, LLCs, sole proprietorships, partnerships, and small businesses, and income tax. At the start, with the plan to drop them in reverse order. This would set our baseline, which would match pretty much what the Government already gets at the time of change. % Rates rising and falling with what was needed last year, no projections on government for next year,

Government would get the funds from the previous year, then set the budget; when it runs out, it runs out (with essential services secured); government shuts down till the next year. If we like it that way, we can keep doing it that way. Or next year rates go up. Extra left over? Refund, and then rates go down. Special "Tax", required anonymous submissions, no questions asked, project fund with a list of what we need to do, send whatever you want. i.e., igniting Jupiter =) Or schools, roads, and bridges on top of what is already budgeted. Head starts on next year, etc. Give 5% to the rest of the world and let them fight over it. I chose arm wrestling, maybe thumb or whoever needs it the most…

For all, a day a week! To start, I'd LOVE an hour a week but… Machines? Maybe in the future. What to do with all that free time….? Can we behave? Want to build some stuff?

On the moon would be one for sure. What else do we want? If we want to think long term…. Telescopes and obsessive data collection and simulation so we stop guessing if we mess with nature on a cosmic scale. If we haven't accidentally done so already.. We need to know as much as we can about what everything up there is doing to the finest detail possible. What would this take? In terms of possible vs. near vs. far are the first questions we need to answer. With the goal of knowing what's happening everywhere we can see, in real time, all of the time, out there. Real-time, continuous mapping of everything observable, and all that is not, to try and infer what else might be there and how much…
