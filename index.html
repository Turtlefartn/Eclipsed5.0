Your site is ready to build on

This is a clean, free GitHub Pages starter — no branding, no ads, yours to keep. Edit it in the browser, publish, and it’s live. No build step.

How editing works

  1. Go to your repo on GitHub and press . — github.dev (VS Code in the browser) opens.
  2. Edit any .html file, commit, and GitHub Pages republishes in 1–2 minutes.
  3. To change the menu/footer everywhere, edit one file only: assets/nav.js

See the example page →

Add a page

Copy pages/example-page/, rename the folder, edit its index.html. That’s it — its URL will be /pages/your-name/

For re-uploaded artifacts: drop each old page into its own folder like that. I can fix its internal links, strip dead muse.ai/s/ links, and hook it into the shared nav.

Custom domain (optional, free on GitHub)

Repo → Settings → Pages → Custom domain, then add the DNS records GitHub shows you. HTTPS is free and automatic.
